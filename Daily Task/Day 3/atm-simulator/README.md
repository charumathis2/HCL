# ATM Simulator

## Day 3 - Control Flow + Maven

A simple console-based ATM simulator built using Java.

## Features

- PIN authentication with 3 attempts
- Check account balance
- Deposit money
- Withdraw money
- Input validation
- ATM menu using `do-while`
- Menu selection using `switch`
- `break` and `continue`
- Maven project configuration
- Maven `dev` and `prod` profiles

## Technologies Used

- Java
- Maven
- VS Code
