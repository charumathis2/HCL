# Day 2 - Language Fundamentals + Git Fundamentals

## Java Task

Created a Monthly Usage Analyzer using:

- Variables
- Data types
- Arrays
- Constants
- Type casting
- Operators
- Ternary operator
- 2D arrays
- long data type

## Features

- Stores usage for 12 months
- Calculates total usage
- Calculates average usage
- Finds maximum usage
- Finds minimum usage
- Assigns a grade using the ternary operator
- Demonstrates long for large values
- Stores usage data for 3 houses using a 2D array
